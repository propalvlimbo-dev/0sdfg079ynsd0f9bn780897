# Формат имени клана — частичное обновление

При остановленных сервере и рестартере, после резервного копирования, `python3 install.py /root/RW_GRIEF /root/elytrix-backups --stopped --backed-up` меняет только известную строку `clanNameFormat: "&8[%clan%&8]"` в живом NClans-конфиге на `%clan%`. Если эта строка уже имеет нужное значение, ничего не делает. Любой другой формат/дубликаты отклоняет; приватный оригинал при изменении сохраняется за пределами каталога сервера. Без проверки работающих процессов на других хостах/контейнерах; остановить сервис вручную. Базы, названия кланов, `clanChatPrefix`, TAB-конфиги и другие настройки не меняются. После полного запуска проверить таб и надголовный тег: скобки, добавленные не NClans, не затрагиваются.

В репозитории нужный формат уже стоит, но конфигурация боевого сервера может отличаться. Проведены тесты на изолированных копиях и моках; на VDS и в игре не проверялось. Этот архив не устанавливает модели, аксессуары, другие обновления или ядро.
