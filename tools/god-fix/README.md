# Запрет подбора при Essentials /god

`ElytrixGodPickup.jar` отменяет `EntityPickupItemEvent` только для игроков с
`Essentials.getUser(player).isGodModeEnabled()`. Сам по себе `/fly` не проверяется
и подбор не ограничивает. При невозможности проверить состояние конкретного игрока
подбор блокируется и в консоль пишется предупреждение; при недоступности Essentials
плагин не запускается. Другая реализация god-mode не отслеживается.

Компиляция и Java-тесты проведены с заглушками, не с настоящим сервером.
Испытать сочетания god/fly, другие плагины и отключение зависимостей на тестовом
сервере. Не ставить одновременно старый экспериментальный
`ElytrixGameplaySafety-test.jar`, который содержит аналогичную обработку.
