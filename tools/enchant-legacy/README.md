# Совместимость книг CloudEnchants со старыми метками

В найденных предметах ElytrixAir, ElytrixGrowGarden и ElytrixCrafts книги имеют
строковые PDC-метки `really-enchants:telepation = TELEPATION_BOOK`,
`really-enchants:woodcutter = WOODCUTTER_BOOK`, `really-enchants:stealer =
STEALER_BOOK` и аналогичные метки других книг. Существующий `CustomEnchantManager`
распознавал `minecraft:<ключ>`, но не `really-enchants:<ключ>`. Из-за этого
запасённые книги старого формата не распознаются обработчиком наковальни.

Патч добавляет точную проверку старых PDC-ключей, не заменяет старые предметы и не
определяет книги по одним только названиям/lore. Существующая проверка minecraft
и ограничения применимости/конфликтов остаются. Новое зачарование по-прежнему
маркируется исходным плагином. У `*_BOOK` требуется тип ENCHANTED_BOOK; на других
предметах распознаётся только точное имя энчанта. Патч затрагивает только
CloudEnchants JAR и не меняет данные игроков.

Оригинальный JAR из checkout SHA-256:
`ce91ca2de7db60dfbd2d44a9adfa9f182394dea1cb61a4f2b0e09896e8241a9d`.
Бинарный патч через ASM добавляет один ранний вызов к `has`, не пересобирая
остальные части плагина. Статическая проверка ASM и тесты метода на заглушках API
прошли; **на настоящем Bukkit/Leaf не проверено**. Проверить отдельно старые
и новые книги трёх типов, применимость предметов, конфликт Бур/Телепатия и
Светлячок/Грабитель, клики обычные/shift, предметы с заполненным инвентарём,
уже зачарованное оружие и фактическую работу эффектов, в том числе после рестарта.
