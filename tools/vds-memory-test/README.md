# Эксперимент с начальным heap на VDS

`install.sh` меняет только отдельную строку `-Xms10G` на `-Xms8G` в живом
`/root/RW_GRIEF/start.sh`, оставляя `-Xmx10G` и другие параметры нетронутыми.
Перед заменой создаётся резервная копия рядом с файлом. Скрипт откажется от
работы, если исходные параметры отличаются или неоднозначны. Проверка синтаксиса
не запускает сервер. Опциональный аргумент — путь к тестовой копии start.sh.

Это обратимый эксперимент, а не доказанное исправление лагов. Меньший начальный
heap может расшириться до 10 ГиБ и не гарантирует сохранения свободной памяти;
изменение также может повлиять на GC. Для применения требуется полный новый запуск
JVM именно через изменённый файл, обычный внутриигровой restart может не перечитать
его. Способ безопасно остановить автоперезапуск зависит от метода запуска.
