# Щупальца Канэки — черновик модели, не установка

В `elytrix_kaneki_tentacles.bbmodel` — экспериментальная модель в формате
Blockbench с четырьмя красными объёмными щупальцами и циклом `idle`. Текстура
нарисована программно пиксель-артом; сторонних изображений и ИИ-генерации нет.
`kaneki_schematic.png` — схематический вид сзади для оценки формы, **не скриншот
из Minecraft и не результат рендера ModelEngine**. Повторная генерация: `python3
generate.py` (Pillow); статические проверки: `python3 test_model.py`.

Эта модель ещё не подключена к ElytrixFreakModel или ModelEngine, не запечена в
ресурспак, не испытана настоящим `BlockbenchParser`, не показана клиенту и не
может быть надета. Геометрия, масштаб, цвета, плавность и нахождение на спине
требуют проверки и доработки в игре. Не копировать её в боевую сборку как готовую.
Существующие крылья и нимб не изменены.

Требования для последующей интеграции:
- `/аксессуары` открывается всем; использование на текущем этапе только для
  администраторов, с расширяемой моделью прав для будущих продаж за риллики.
- Визуальная косметика без слота брони; не менять существующие вещи игроков,
  характеристики брони и текущие крылья/нимб. Без боевых способностей.
- Продумать конфликты моделей на спине, скрытие в первом лице, пересоединение,
  телепорт, смену мира, смерть, рестарт и отзыв разрешения; не допускать дюпов.
- Сделать меню с ресурс-паком, но добавлять только свои assets; не перезаписывать
  live RP целиком. Проверить Unicode-команду на реальном клиенте и Leaf.
- Проверить регистрацию, видимость других игроков, повороты, анимацию, задержку,
  совместимость и производительность вместе с текущим WornAngelRig.
- Не трогать живые базы и старые покупки до проектирования и отдельного бэкапа.
