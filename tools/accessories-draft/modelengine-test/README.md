# Изолированный тест черновой модели

`JAVA=/path/to/java ECJ=/path/to/ecj.jar sh tools/accessories-draft/modelengine-test/run.sh` запускает проверки с ModelEngine 4.1.0 из репозитория (SHA-256 `d24b7d4e865f5453cb2947ec87bd3549e571c7d7927cd22e0c6927b03426090d`). Весь временный classpath автоматически удаляется; JAR и серверные файлы не изменяются.

В первом тесте реальный `BlockbenchDeserializer` читает 14 элементов, корневую группу, текстуру и анимацию. Во втором реальный `BlockbenchParser.populateBlueprint` и `populateAssets` выполняются при заглушках API, конфигурации, генератора, Bukkit и некоторых контейнеров fastutil. Созданы четыре item-модели и 14 элементов, одна текстура и `idle`; собранных предупреждений нет. Во временной копии `TMath` отключена инициализация через Bukkit; парсер при этом не патчится.

**Ограничения:** тест использует `Use-New-Rotation=true`, а в копии текущего конфига проекта — `false`. Существующий путь `false` через RotationSolver не проверен, реальный конфиг не менять ради теста. Регистрация behavior parser пропущена. Генерация конечного клиентского ресурспака, запуск ModelEngine/Leaf, анимация в игре, установка, косметическая привязка к игроку и совместимость с существующими крыльями не проверены. Это не установка и не доказательство игровой работоспособности.
