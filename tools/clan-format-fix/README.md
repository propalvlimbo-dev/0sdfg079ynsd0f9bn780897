# Скобки клана — точечный тестовый патч

В исследованном NClans `%nclans_clan_name%`, использующийся TAB как `tabsuffix`
и `tagsuffix`, подставляет формат из `clanNameFormat`. Дефолт JAR содержит
`&8[%clan%&8]`; подготовленная Git-копия уже содержит `%clan%`, но пользователь
её не устанавливал. Live-версия конфига и JAR не известны. Скобки также могут
быть частью имени клана или добавляться другим плагином, поэтому убрать их без
проверки live-источника нельзя.

Скрипт работает **только с изолированной копией** (боевой путь запрещён), не
читает и не пишет базы, изменяет ровно известное значение, не перезаписывает
другие настройки. Он не устанавливает плагин. Предварительный просмотр:
`python3 patch.py /path/to/offline-copy/plugins/NClans/config.yml`; применить к
остановленной копии после бэкапа: та же команда с `--apply`. Если исходная строка
отличается или дублируется, скрипт откажет. Для обновления отображения необходим
полный перезапуск тестового сервера и проверка плейсхолдера и TAB в игре.
