# Рандомное яйцо: тестовый комплект

Сборка заменяет только `plugins/ElytrixRandomEgg.jar`, сохраняет имя плагина и PDC
ключ `elytrixrandomegg:random_egg` старых яиц. Для покупки три яйца меню выполняет
одну административную команду `randomeggbuy <игрок>` вместо отдельных списания и
выдачи. Команда проверяет наличие PlayerPoints, баланс и вместимость 3 предметов;
при ошибке вставки восстанавливает сохранённые слоты и пытается вернуть валюту.
Если возврат не удался, пишет `REFUND FAILED` в лог. Cashback вызывается после
успешной покупки. `/randomegg` сохранён для администраторов, теперь также допускает
второй параметр — количество от 1 до 64. Это не глобальная транзакция с БД
PlayerPoints, и потеря питания между разными действиями может требовать разбора.

Яйцо с прежним ключом реагирует на ПКМ по блоку основной рукой. Если другой плагин
уже отменил взаимодействие, защита не обходится. Существо выбирается из живых
spawnable типов; яйцо расходуется только после успешного и валидного призыва, в
креативе не расходуется. На сервере с запрещённым призывом яйцо будет сохранено.

Сборка и имитационные тесты проверены заглушками API, **не настоящими Leaf,
PlayerPoints или клиентом**. Обязательно проверить в отдельной копии: магазин при
достаточном/недостаточном балансе, полный инвентарь и частично заполненный стак,
возврат при неудаче, старые и новые яйца, охраняемые регионы, спавнер, креатив,
другие плагины и поведение после перезагрузки. Не устанавливать отдельно от
соответствующего изменения меню, иначе покупка может не работать.
