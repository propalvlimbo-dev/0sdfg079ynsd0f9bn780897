# CloudQuests: проверка EL+

В обфусцированном обработчике `Class050` команда `/skipquest` делегируется
`Class047.method_0019`. Анализ его байткода показал единственный вызов
`Player.hasPermission("cloudquests.skipquest")`; активная подписка CakeSub сама
по себе это право не устанавливает. `CakeSub` предоставляет `Data.hasActive(name)`,
которая учитывает срок и `forever`. Патч заменяет только этот вызов на проверку:
существующее право **или** активная подписка CakeSub. Если CakeSub недоступен или
проверка не удалась, дополнительных прав не выдаётся. Другие команды и проверки
CloudQuests не меняются, права не сохраняются в LuckPerms. В plugin.yml добавлен
softdepend для корректного порядка загрузки. Плагин CakeSub может отсутствовать —
тогда работает прежняя проверка прав.

Оригинальный JAR SHA-256:
`2f5a212549195ed362dc69f1afb572ecc1a7f6bdfd6cc272a9e2c07c29cd37fc`.
Проверены точное количество замен байткода, ASM BasicVerifier и Java-тесты на
заглушках. На Leaf, в игре и с live-версиями плагинов ещё не проверено. Нужен тест
активной, бессрочной и истёкшей подписки, игрока без подписки, индивидуального
права и лимитов квестов; сравнить используемые JAR с оригинальными хешами.
