# KnockbackSync 1.3.6-dev-b143 (alpha): отдельная установка

Загружается upstream full JAR, объявленный для Bukkit/Paper/Purpur и 1.21.11: https://api.modrinth.com/v2/project/knockbacksync/version/1.3.6-dev-b143 . Проверяются размер 11832714 и SHA-512 `1176d788003f6a58593d6e172e406a6f24e7a730c71068a888ea71934816ea4ac6bd5b7ad4d2cf9de95f6824aba9bca516922e35c540bcc64973c71f7a828a5f`, имя плагина и main-класс. По исходникам upstream full-вариант включает свой relocated PacketEvents; точную работоспособность опубликованного JAR и взаимодействие с другими плагинами здесь проверить не удалось.

Сервер и автоперезапуск должны быть вручную остановлены. Запускать после полноценного бэкапа, включая внешние БД. Установщик не заменяет существующий JAR с именем плагина KnockbackSync и не изменяет существующий конфиг. При отсутствии конфига плагин создаст его при запуске с собственными настройками. Плагин может влиять на поведение боёв, пакетов и античитов; совместимость с DivineMC, Grim и GreatCombat, античитные ложные срабатывания и реальная боевая механика **не проверены**. Это alpha и не гарантия улучшения PvP. Если сервер нестабилен или появляются false-positive, остановить сервер и убрать только добавленный `plugins/knockbacksync-bukkit-1.3.6-dev-b143.jar` за пределы `plugins`, затем запустить снова и сверить логи. Сохранённый каталог настроек не удалять.

Скрипт тестирован на фиктивных JAR и моках, настоящий артефакт и сервер в этом окружении недоступны. Проверки /proc не гарантируют обнаружение всех сервисов/рестартеров. Ничего не запускается автоматически. Это установка **только KnockbackSync**, не решает задачи косметики, `/free`, сундуков или кейсов.

`python3 install.py /root/RW_GRIEF --stopped --backed-up`
