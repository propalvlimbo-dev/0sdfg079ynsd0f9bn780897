# Read-only аудит перед переносом эндер-сундуков

`python3 audit.py /путь/к/остановленной-изолированной-копии` печатает только
агрегированные числа. Ничего не переносит и не печатает имена, UUID, содержимое
вещей или секреты. Поддерживает только NEnderChest SQLite и gzip Java NBT
playerdata, проверяет обе SQLite-конфигурации, валидирует слоты и отказывает на
неподдерживаемых структурах. Пусть администратор отдельно проверит внешние миры,
хранилища, резервные копии и симлинки. Результат — диагностика, не миграция.
